Where is JWT generated, and is it validated on every request?
JWTs are signed in auth/jwt.py using RS256, then attached to the session in auth/login.py. Every incoming request passes through auth/middleware.py, which verifies the signature and expiry before the route handler runs — so validation is enforced globally, not per-endpoint.
